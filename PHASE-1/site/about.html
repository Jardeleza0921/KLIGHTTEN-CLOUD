About

A learning project with a product mindset.

Klightten Cloud explores how a modest self-hosted environment can deliver a coherent cloud-style experience.

The project treats the interface, access model, file experience, operational boundaries, and presentation as parts of the same system. Phase 1 captures the first complete result: a working prototype supported by a separate private administration application.

Discipline

Information technology, web services, systems administration, and interaction design.

Format

A self-hosted prototype with a browser-based client experience and private operator controls.
